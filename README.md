# MetaTruth — Bones × Remedy v0.5.0

## New in v0.5
- Multi-source evidence normalization.
- Tracking-parameter removal and canonical URLs.
- Duplicate evidence suppression.
- Source-quality scoring.
- Claim/evidence relevance scoring.
- Remedy provenance matrix.
- Review-bundle export.
- SHA-256 chained audit events.
- Staging-only deployment.

## Install
Extract the Chrome ZIP, open `chrome://extensions`, enable Developer mode, select **Load unpacked**, and choose the extension folder.

Quality and relevance scores are heuristics. They do not establish truth, guilt, identity, or intent.
